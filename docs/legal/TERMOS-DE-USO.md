Vigência: 26/10/2026. Valem para o aplicativo Cálculos Trabalhistas e Tributários para Windows e para Android.

## 2. O que o aplicativo faz

O aplicativo faz simulações trabalhistas, tributárias, previdenciárias, de pensão alimentícia e de débitos judiciais a partir dos dados que você digita e das tabelas guardadas no próprio computador ou aparelho. Os resultados são estimativas: o aplicativo não é sistema de folha de pagamento, não emite guias oficiais, não transmite declarações e não substitui o trabalho de um contador, advogado ou outro profissional especializado.

Ao usar o aplicativo, você se compromete a:

- conferir os dados informados, como competência, datas, salários, verbas e dependentes, antes de usar um resultado;
- conferir os valores das tabelas, inclusive os atualizados pela internet ou editados por você, com as fontes oficiais da competência;

## 5. Tabelas e atualizações

As tabelas acompanham o aplicativo e podem ser atualizadas pela internet a partir de fontes oficiais e de fontes alternativas, conforme as regras descritas no manual. As páginas consultadas podem mudar, ficar fora do ar ou publicar valores com atraso; nesses casos os dados locais são preservados e a atualização pode não ocorrer. Você pode incluir, editar e excluir registros das tabelas; os cálculos passam a usar os valores gravados.

No Windows, o aplicativo também pode avisar sobre uma versão nova publicada no GitHub do projeto e, com a sua confirmação, baixar e instalar essa versão.
